# 夏以昼 Codex 桌宠

> 给也想让夏以昼在桌面上陪自己一起工作的“小苹果”们。🍎

这个小东西最开始其实就是一个很简单的念头：每天都要看着 Codex 工作这么久，那能不能顺便让夏以昼也在旁边待着？

所以后来一点点把它做成了现在这个桌宠。

他会跟着你的鼠标看来看去；Codex 正在工作、或者有结果等你看的时候，他会有不同的状态；你也可以把他拖来拖去。安静久了，他还会自己睡着。💤

我想尽量把桌宠做得可爱一点，也把安装这件事做得安全一点。这个仓库就是目前整理出来的非官方、非商业版本。

[English](README.md)

## 他会做什么

- 👀 鼠标绕着移动时，会朝完整的 360° 方向看过去。
- Codex 在忙的时候，会一直保持工作动画。
- 有新结果还没看时，会停留在查阅状态。
- 可以直接按住他拖来拖去。
- 真正闲置一段时间后会睡着；你碰他、拖他，或者 Codex 又开始工作时，他会醒来。

这些通用互动能力来自单独维护的 [Codex 桌宠互动扩展](https://github.com/fyhaira/codex-pet-interaction-enhancer)，安装器只使用经过验证的固定版本。

## 先说一下目前的状态 ⚠️

这还是一个 **Developer Preview / Experimental（开发者预览 / 实验性）** 的同人小项目。目前只测试并支持下面这些精确版本。版本对不上时，安装器会直接停下来，不会继续修改任何东西。

## 目前支持的版本

| Codex/ChatGPT 版本 | 构建号 | 平台 | 状态 |
|---|---:|---|---|
| 26.908.40834 | 8881 | macOS arm64 | 支持 |

现在只支持表里的 macOS arm64 组合。版本、构建号、平台或架构有任何一项不同，安装器都会安全停止。

## 怎么安装 🛠️

1. 从对应的 GitHub Release 下载版本化 ZIP 和 `checksums.txt`。
2. 先核对 ZIP 的校验值。
3. 完全退出 ChatGPT/Codex、Codex Pet Toolkit、QA 副本和它们留下的辅助进程。
4. 打开 `Xia Yizhou Codex Pet.app`。
5. 先点 **Dry Run**，看看识别出的版本和构建号是否正确；确认没问题后再点 **Install**。
6. 安装器会另外创建并启动一份由它管理的运行时副本，不会就地修改 `/Applications/ChatGPT.app`。

这个项目**目前还没有经过 Apple 公证**，所以打开下载的应用时，macOS 可能会显示标准安全提示。请不要全局关闭 Gatekeeper。当前比较安全的打开方式和发布状态写在[安装说明](docs/installation.md)里。

## 怎么卸载

先把 Codex 和前面提到的那些程序完全退出，再打开同一个安装器，选择 **Uninstall**。

卸载时，安装器只会删除它能确认是自己装进去的东西。如果安装前就已经有一份内容完全相同的夏以昼桌宠，它会把那份保留下来。更多细节见[卸载说明](docs/uninstall.md)。

## 安装时会怎么保护原来的环境

- 官方 ChatGPT/Codex 应用一直保持只读，不会被就地修改。
- 需要改动的运行时会先在临时目录里做好并检查完整，确认没问题后，才会放到单独管理的副本里。
- 安装器会逐项检查精确构建清单、源文件哈希、ASAR 完整性、签名、桌宠文件哈希和身份对应关系；任何一项对不上都会停下来。
- 如果官方应用、管理副本、QA 副本，或者其他正在使用 Codex 资料的进程还没退出，安装器不会继续写入。
- 安装和卸载都有有限范围的备份、操作锁、回滚和所有权检查。
- 你的任务、项目、登录信息、个人资料、其他桌宠和日用 Toolkit 都不归这个安装器管理。

## 仓库里有什么 / 没有什么

Git 仓库里有安装器源码、三个最终桌宠文件、说明文档和发布构建工具。

这里**没有** Codex 二进制、管理运行时、Node 二进制、`.app`、构建缓存、用户资料、备份、诊断记录、官方参考图或私人源美术文件。

制作 Release 时，构建脚本会下载并校验指定的官方 Node.js 归档，以及固定提交的互动扩展。最后的 Release ZIP 可以把这些校验过的依赖放在安装器应用里面，但它们不会提交到 Git 仓库。

## 现在还有哪些限制

- 只支持 macOS arm64。
- 只支持表里列出的精确 Codex 构建。
- 目前还没有经过 Apple 公证。
- Codex 更新后，通常需要重新验证兼容清单并发布新版安装器。
- 这是非官方项目，也依赖 Codex 的内部结构；以后更新时可能会暂时失效。

更多信息见[兼容性](docs/compatibility.md)和[故障排查](docs/troubleshooting.md)。
