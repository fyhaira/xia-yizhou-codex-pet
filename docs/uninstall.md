# Uninstall

1. Quit the official ChatGPT/Codex app, the managed Xia runtime, Codex Pet Toolkit, and QA or diagnostic copies.
2. Open the same Xia Yizhou Codex Pet installer.
3. Select **Uninstall**.
4. Wait for the success result, then use **Refresh** to confirm that launch and uninstall actions are disabled.

Uninstall removes the installer-owned managed runtime, active metadata, verified alias metadata, transaction state, and installer-owned pet payload only when ownership and hashes match. An identical Xia package that existed before installation is classified as preserved pre-existing state and is not removed.

Uninstall does not restore whole profiles or remove tasks, projects, authentication, unrelated pets, the official application, or Codex Pet Toolkit.
