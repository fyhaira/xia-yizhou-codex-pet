# Licensing structure

This repository deliberately separates four licensing layers:

1. **Installer code and original documentation** — covered by the repository's Xia Yizhou Codex Pet Personal Use License 1.0 in `LICENSE`.
2. **Xia Yizhou payload assets** — covered only by `ASSET-TERMS.md`; they are not placed under an open-source software license.
3. **Codex Pet Interaction Enhancer** — remains a separate project under its own Personal Use License. This source repository does not vendor or relicense it. Release construction fetches one exact commit. Redistribution inside a release installer requires the enhancer copyright owner's separate authorization and preservation of its license.
4. **Node.js and npm dependencies** — remain under their respective licenses. Release bundles preserve Node's full license and the dependency license files indexed by `THIRD-PARTY-NOTICES.txt`.
